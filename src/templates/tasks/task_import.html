  • {% blocktranslate %}date: dd/mm/aaaa ou aaaa-mm-dd. É o início da tarefa, e também o término quando o status não é DOING.{% endblocktranslate %}
  • {% blocktranslate %}id: identificador da tarefa no sistema de origem. Obrigatório e único por projeto no arquivo.{% endblocktranslate %}
  • {% blocktranslate %}time: horas com vírgula ou ponto (3,8 = 3:48), ou H:MM. Vazio = 0.{% endblocktranslate %}
  • {% blocktranslate %}desc: nome da tarefa.{% endblocktranslate %}
  • {% blocktranslate %}status: DOING, REVIEW, DONE ou REJECTED. Vazio = DOING.{% endblocktranslate %}
  • {% blocktranslate %}github (coluna opcional): o repositório do projeto da tarefa, como dono/repositorio ou a URL. A tarefa vai para o projeto desse repositório, que é criado se ainda não existir. Vazio = o projeto escolhido abaixo.{% endblocktranslate %}

{% blocktranslate %}Separador ;, , ou tab. Se alguma linha tiver erro, nada é importado.{% endblocktranslate %}
